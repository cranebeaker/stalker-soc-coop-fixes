# Опциональный режим 8 (addon 8.1, только проверенная x86 DLL)

Обычная сборка и релиз сохраняют исходную ёмкость четыре игрока. Опциональный
пакет содержит все выбранные обычные исправления и данные режима 8: 18 файлов
level.game, восемь карточек лобби и счётные пределы cooperative/ammo. Счётчик Ready
показывает число подключённых игроков. Хосту и клиентам нужен один и тот же пакет
и одинаковый отпечаток addon. Режим экспериментальный: проверка лобби и сети
сама по себе не подтверждает прохождение всей кампании.

Сборка из репозитория, без отдельного архива игры и приватных рабочих путей:

```text
python build.py --player-limit 8
python tools/release.py 1.4.7 --player-limit 8 --no-boot
```

Результат — отдельный `SoC_COOP_fixes_v1.4.7_players8.zip`. Команда ничего не
публикует и не создаёт тег. Для проверки установщика нужны PowerShell (при
необходимости `COOP_PWSH`) и локальная исходная DLL (`COOP_TEST_DLL` либо DLL/её
исходная копия в игре из `XRMPE_GAME`). Проверяются только копии и искусственный
addon; игра не запускается. Явный `--no-installer-test` пропускает эту проверку,
что нужно учитывать вместе с отчётом релиза. Формат обычного релиза сохраняется.
Чужая DLL не включается в репозиторий или ZIP.

Закройте игру и лаунчер, распакуйте пакет и запустите `installer/install.bat`.
Укажите `coop.addon` или каталог игры. Для установки в Windows и штатного выбора
лимита Python не нужен. Установщик сверяет DB и точный fingerprint/сигнатуры DLL,
включая отдельную dedicated DLL при её наличии. Неизвестные DLL, лишние DB модов,
несовместимые/неполные резервные копии и loose-переопределения cooperative, UI или
level.game вызывают отказ, в том числе при другом регистре имён и через связанные
каталоги. Восстановите исходный addon либо самостоятельно устраните конфликт:
установщик не удаляет посторонние DB молча.

Поддерживаемая исходная `bin/xrGame.dll`: 7 915 520 байт, SHA256
`ef430b5f39628dcd03a4dd6e44b114559549660dd06d3f3218296d1eee1c462e`.
Исправленная DLL:
`de8e7b892203abc0e7a667b1a56ad0844140f02a82461e8432edc6a3150f2860`.
Меняются ровно четыре immediate-байта `04`→`08`; x64 и другие версии не принимаются.

Рядом с DLL сохраняется `xrGame.dll.cap8-original`, рядом с addon —
`coop.addon.cap8-original` и его `.sha256`. Сохраните их: повторная установка
исправленной DLL без проверяемых исходников запрещена. Нужен запас места для
полной резервной копии и подготовленного addon (несколько ГБ каждый). Сначала
публикуются данные, затем DLL; профиль `coop_player_limit_profile.json` появляется
в корне игры после успеха всех замен. При ошибке запускается откат. Сообщение
`ROLLBACK INCOMPLETE` перечисляет файлы, которые ОС не дала восстановить, и пути
для восстановления; до их восстановления игру не запускайте и не удаляйте эти файлы.

Для возврата исходных addon и DLL используйте тот же пакет:
`installer/install.bat -Uninstall`. Резервные копии сохраняются. Восстанавливается
полный addon до первой опциональной установки, включая старый обычный DB
исправлений, если он там был. После этого установите нужный обычный пакет.
Если установленный DB или базовый addon изменился после установки, восстановление
откажет и сохранит новые данные для ручной проверки. Обычный пакет не устанавливает
и не удаляет DB, пока остаётся профиль режима 8 либо исправленная DLL: сначала
восстановите исходники соответствующим опциональным пакетом. Другие имена addon
не принимаются: установка и восстановление режима 8 работают только с
`game/addons/coop.addon`.

Отдельный тест symlink может явно пропускаться в Windows без прав на создание
ссылок; основные проверки установки, восстановления и отката продолжают выполняться.

Хост Windows запускает `Start-Server-1-8.bat`, вводит корень game и лимит сессии
1–8 (Enter = 5). Можно передать параметры явно:

```text
Start-Server-1-8.bat -GamePath "D:\X-Ray Multiplayer Extension\game" -Players 5
python tools/start_coop_server.py --game "D:\X-Ray Multiplayer Extension\game" --players 5
```

Хост Linux/Wine использует Python 3.10+ и уже инициализированный отдельный prefix:

```text
python3 tools/start_coop_server.py --game /absolute/game --players 5 --wine /path/to/wine --wine-prefix /absolute/existing-prefix
```

Перед запуском проверяются DLL, фактический DB/hash и физический порядок DB
`[gamedata.db0, gamedata.db1, zzz_soc_coop_fixes.db]`; icon/metadata допустимы
между ними. Python читает JSON из корня игры либо явный `--profile /путь/profile.json`.
Старый фиксированный standalone-профиль применяется только при отсутствии JSON.
Python `--dry-run` печатает команду без проверки данных и запуска. PowerShell
`-DryRun` проверяет данные и печатает команду. Сохранённые host settings молча
не меняются.

Ёмкость 8 отделена от `maxplayers=N` конкретной сессии. Сервер стартует на Кордоне,
public=0, порт 5495. Имеющиеся формулы баланса считают живых игроков; пределы
`max_factor=2.5`, `max_extra_members=6`, одна группа подкрепления на smart и
фиксированный множитель урона не повышаются. Сохранённый `coop_settings.ltx` с
явным счётным пределом 4 имеет приоритет над новым умолчанием — при необходимости
проверьте свою сохранённую настройку. Новая формула масштабирования обычного лута
по размеру группы не добавлялась.
